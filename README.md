# 🧠 منصة تحليل الشخصية والذكاء المتعدد (Personality & Intelligence Portal)

منصة تفاعلية متكاملة مبنية بلغة **Python** وإطار عمل **NiceGUI**، تهدف إلى مساعدة المستخدمين على فهم أنفسهم بشكل أعمق من خلال اختبارين علميين مشهورين في واجهة واحدة أنيقة.

---

## ✨ المميزات (Features)

* **اختبار MBTI:** تحليل الشخصية بناءً على 36 سؤالاً لتحديد نمطك المكون من 4 حروف (مثل INTJ, ENFP).
* **اختبار الذكاءات المتعددة:** قياس 7 أنواع مختلفة من الذكاء بناءً على نظرية "هوارد جاردنر".
* **واجهة مستخدم تبادلية (Tabs):** تنقل سلس بين الاختبارين دون فقدان التقدم.
* **أشرطة تقدم تفاعلية:** متابعة نسبة الإنجاز في الاختبار بالوقت الفعلي (Percentage %).
* **تصميم متجاوب:** واجهة مريحة للعين تعمل على الحاسوب والهواتف الذكية.
* **نتائج فورية:** عرض النتائج فور الانتهاء مع تمثيل بصري بالنسب المئوية.

---

## 🛠️ المتطلبات التقنية (Requirements)

قبل البدء، تأكد من تثبيت **Python 3.8** أو أحدث على جهازك.

---

## 🚀 طريقة التثبيت والتشغيل (Installation)

اتبع الخطوات التالية لتشغيل المشروع محلياً:

### 1. تحميل المشروع
قم بتحميل ملفات الكود إلى مجلد خاص على جهازك.

### 2. إنشاء بيئة افتراضية (اختياري ولكن ينصح به)
```bash
python -m venv venv
# لتفعيلها على Windows:
venv\Scripts\activate
# لتفعيلها على Mac/Linux:
source venv/bin/activate
```bash

3. تثبيت المكتبات اللازمة
استخدم ملف requirements.txt لتثبيت الأدوات المطلوبة بضغطة واحدة:

```bash
pip install -r requirements.txt
```bash

4. تشغيل التطبيق
قم بتشغيل الملف الرئيسي (على سبيل المثال main.py):

```bash
python main.py
```bash

بعد التشغيل، سيفتح التطبيق تلقائياً في متصفحك على الرابط: http://localhost:8080

📊 هيكلة الاختبارات داخل التطبيق
1️⃣ تبويب MBTI
يعتمد الاختبار على المفاضلة بين خيارين لتحديد الميول في أربعة محاور أساسية:

الانبساط (E) مقابل الانطواء (I).

الحس (S) مقابل الحدس (N).

التفكير (T) مقابل الشعور (F).

الحكم (J) مقابل الإدراك (P).

2️⃣ تبويب الذكاءات المتعددة
يعتمد على تقييم العبارات من 1 إلى 5 لقياس:

الذكاء اللغوي والمنطقي.

الذكاء الموسيقي والحركي.

الذكاء البصري والاجتماعي والذاتي.

📂 ملفات المشروع (Project Structure)
main.py: الملف الأساسي الذي يحتوي على الكود البرمجي والواجهات.

requirements.txt: قائمة المكتبات البرمجية المطلوبة.

README.md: دليل المستخدم (هذا الملف).
